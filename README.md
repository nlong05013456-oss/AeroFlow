# ✈️ AeroFlow

### Aviation Data Warehouse, ELT Pipeline & Analytics Platform

> ⚙️ **Data Engineering** · 📊 **Data Analytics** · ☁️ **Cloud**

AeroFlow is an end-to-end aviation data platform built on **Google Cloud Platform (GCP)** for collecting, processing, storing, validating, and analyzing flight and weather data.

The project combines **Data Engineering and Data Analytics** into a practical cloud-based platform, with a web application for flight lookup, operational monitoring, and analytical insights.

---

## 🎯 Project Overview

AeroFlow starts from a business-oriented question:

> **How can aviation data be transformed into reliable information and actionable insights for monitoring flight performance?**

The platform follows an end-to-end data workflow:

```text
Business Requirements
        ↓
    Data Sources
        ↓
   Data Ingestion
        ↓
      Data Lake
        ↓
   ELT / Transformation
        ↓
   Data Warehouse
        ↓
 Data Quality & Validation
        ↓
   Data Analytics
        ↓
 Business Insights
        ↓
 Web Application
